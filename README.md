# СМАК — Доставка їжі

## Про проєкт

**СМАК** — це вебсайт для замовлення їжі онлайн. Він дозволяє переглядати меню, шукати страви, додавати їх у кошик та оформлювати замовлення.

## Основні можливості

- Перегляд меню та категорій страв.
- Пошук і фільтрація страв.
- Кошик із можливістю змінювати кількість товарів.
- Реєстрація та вхід користувачів.
- Оформлення та перегляд замовлень.
- Адміністративна панель для керування меню та замовленнями.
- Адаптивний дизайн для телефонів і комп'ютерів.

## Технології

- Python
- Django
- HTML
- CSS
- SQLite
- Bootstrap

## Як запустити проєкт

### 1. Завантажити проєкт

Завантажте проєкт та відкрийте папку `food-shop` у терміналі.

### 2. Створити віртуальне середовище

```bash
python -m venv .venv
```

### 3. Активувати середовище

Windows:

```bash
.venv\Scripts\activate
```

### 4. Встановити залежності

```bash
pip install -r requirements.txt
```

### 5. Підготувати базу даних

```bash
python manage.py migrate
```

### 6. Завантажити меню

```bash
python manage.py load_menu
```

### 7. Створити адміністратора

```bash
python manage.py createsuperuser
```

Введіть ім'я користувача, електронну пошту та пароль для входу в адміністративну панель.

### 8. Запустити сайт

```bash
python manage.py runserver
```

Після запуску відкрийте сайт у браузері:

http://127.0.0.1:8000/

Адміністративна панель:

http://127.0.0.1:8000/admin/
